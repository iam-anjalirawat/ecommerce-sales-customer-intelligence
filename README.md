# E-Commerce Sales & Customer Intelligence Dashboard

An interactive Power BI dashboard analyzing e-commerce sales, customer, and returns data for 2010–2011, built from a raw Excel dataset.

## Dashboard Preview

![Dashboard Screenshot](https://github.com/iam-anjalirawat/ecommerce-sales-customer-intelligence/blob/main/Screenshot%202026-08-16%20181542.png)

## Overview

This project cleans and models raw transactional e-commerce data in Excel, then builds an executive-level performance dashboard in Power BI to track revenue trends, top products, customer behavior, and return rates.

## Key Metrics Tracked

- Net Revenue: 10.62M
- Total Orders: 21K
- Total Customers: 4K
- Average Order Value: $516.9
- Return Rate: 2.01%

## Key Insights

- 2011 revenue surged to $9.8M compared to $0.8M in 2010
- United Kingdom is the dominant market, contributing ~$9.0M in revenue
- November recorded the highest order activity of the year
- Return rate remained low at 2.01% of total transactions

## Dashboard Features

- Monthly revenue trend with order volume overlay
- Year-over-year revenue comparison
- Top 10 products by revenue
- Top 10 countries by revenue
- Sales vs returns breakdown
- Revenue by day of week
- Revenue by hour of day
- Interactive filters: Year, Quarter, Country

## Tools Used

- Power BI — data modeling and dashboard visualization
